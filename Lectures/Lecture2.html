Language Models
A Quick Recap

Foundations before applying LMs to geo tasks — NLP, transformers & attention

What is Natural Language Processing?

Definition
NLP is the field of AI that enables computers to understand, interpret, and generate human language in a way that is meaningful and useful.
Core Goals
1
Understanding — parse meaning from text
2
Ambiguity resolution — same word, different meanings
3
Context awareness — meaning depends on surrounding words
4
Generation — produce coherent, relevant text
🌍 GeoAI relevance
Geographic knowledge is locked in text: news, reports, papers, social media. NLP is the key to unlocking spatial information from text corpora.

What is a Language Model?

Core Idea
A Language Model learns a probability distribution over sequences of tokens. Given context, it predicts what comes next — building rich contextual representations of meaning.
The Transformer Pipeline
1
Tokenize — split text into tokens (words, punctuation, or word-pieces depending on the tokenizer)
2
Embed — map tokens to dense vectors + positional encoding
3
Attend — self-attention relates every token to every other
4
Output — predict next token or task-specific labels

The Attention Mechanism

Three Projections
Q Query — "What am I looking for?"
K Key   — "What do I offer?"
V Value — "What do I pass on?"
THE FORMULA
Attention(Q,K,V) = softmax(QKT/√dk)·V
Scale ÷√d_k prevents gradient issues
Key Insight
Every token can directly attend to every other token in one step — no sequential bottleneck!

Geo Parsing
From Text to Place

NER for geographic entity extraction · Geocoding with Nominatim · Building a geographic layer from a text corpus

Named Entity Recognition (NER)

Episode 1 · Entity Extraction
NER is the task of locating and classifying named entities in text into predefined categories — persons, organizations, locations, dates, and more.
Standard Entity Types
LOC — Location (cities, countries, rivers)
PER — Person names
ORG — Organizations
DATE — Temporal expressions
Example Sentence
On June 12DATE , Dr. Maria SantosPER from UNEPORG reported wildfires across the Amazon BasinLOC in BrazilLOC and BoliviaLOC . Prof. James ChenPER of NASAORG noted fires reached the PantanalLOC , threatening ManausLOC and Santa CruzLOC .
🌍 Geo Focus
For GeoAI we specifically focus on LOC entities — extracting place names from large text corpora to create spatial datasets for analysis and mapping.

Challenges in Entity Extraction

⚡ Geo-Ambiguity
"Paris" — city in France or Paris Hilton?
"Jordan" — country in Middle East or Michael Jordan?
"Memphis" — Tennessee city or ancient Egypt?
📏 Multi-token Spans
Entities often span multiple tokens:
"New York City Police Department"
"the Amazon River basin"
The model must detect exact boundaries.
🌐 Out-of-Vocabulary Places
Remote villages, newly named locations, transliterated names from other scripts — the model may never have seen them during training.
🔗 Nested Entities
"[Bank of [America]LOC]ORG"
ORG contains LOC. Standard flat NER models struggle with nesting.
📄 Domain Shift
A model trained on news may fail on scientific papers, historical documents, or social media geo-tagged posts.

Tokenization & IOB Tagging

Step 1 — Tokenize
Text is split into sub-word tokens using the given tokenizer. Each token is then classified independently by the NER model.
Step 2 — IOB Labeling Scheme
Each token receives a label:
B-LOC = Beginning of a location entity
I-LOC = Inside (continuation) of entity
O = Outside any entity
Why IOB? Multi-token entities need a way to mark start vs continuation:
“New” → B-LOC   “York” → I-LOC   “City” → I-LOC
IOB Tagging Example

How NER Models Identify Entities

Transformer-based Token Classification
Modern NER uses pre-trained transformers fine-tuned with a token classification head. The model produces one IOB label per token.
The Pipeline
1
Input: [CLS] token1 ... tokenn [SEP]
2
Transformer encoder: produces contextual embeddings h1...hn
3
Linear head: W·hi → logits over IOB label set
4
Softmax → per-token probability over {B-LOC, I-LOC, B-PER, ..., O}

What is Geocoding?

Geocoding converts a place name or address into geographic coordinates (latitude, longitude).
→ Forward Geocoding
"Eiffel Tower, Paris"
  → lat: 48.8584°N
  → lon: 2.2945°E
  → type: tourism/attraction
← Reverse Geocoding
(48.8584°N, 2.2945°E)
  → "Eiffel Tower, Paris, France"
🌍 Why it Matters for GeoAI
Text corpora contain vast geographic information. Geocoding converts extracted place names into spatial points and polygons for GIS analysis and visualization.

Dominant Geocoding APIs

📺 Google Maps Geocoding API
The industry gold standard. Powered by Google's massive location database and Street View imagery.
✅ Extremely accurate, global coverage
✅ Handles typos, partial addresses, ambiguity
✅ Returns structured address components
⚠️ Commercial — paid API with usage limits
⚠️ Closed data — knowledge base not inspectable
🍏 Nominatim (OpenStreetMap)
Open-source geocoder built on the OpenStreetMap knowledge base. Widely used in academia and open GeoAI research.
✅ Free & open source — no API key required
✅ Transparent — OSM data is fully inspectable
✅ Supports structured + unstructured queries
⚠️ Coverage depends on OSM community contributions
⚠️ Less robust on informal or partial addresses
Other options
HERE Maps · Mapbox Geocoding · Azure Maps · Pelias (open) · GeoNames

How Nominatim Works

The OSM Knowledge Base
Nominatim queries the OpenStreetMap database — a crowd-sourced geographic knowledge base with billions of tagged entities: nodes, ways, and relations.
Query Processing Pipeline
1
Parse query — split into tokens, identify structural components (city, country, postcode)
2
Search candidates — query the OSM search index for matching entities
3
Rank results — score by importance (population), type relevance, geographic plausibility
4
Return result — lat/lon centroid + bbox polygon + OSM tags

Latent Space Representation

What is a Latent Space?
Imagine giving every word a location on a map. Words with similar meanings are placed close together; unrelated words are far apart. That "map" is the latent space — a mathematical coordinate system where position = meaning.
What are "Latent Coordinates"?
A word is assigned a list of numbers (e.g. 300 numbers). These numbers are its coordinates in the latent space — its hidden fingerprint of meaning.
Just like GPS coordinates locate a city on Earth, latent coordinates locate a word in meaning-space.
Key Properties
✦ Semantic similarity = geometric closeness
✦ Relationships preserved as vector directions
✦ Analogies = vector arithmetic

Combining Vision & Language Embeddings

The Challenge
Language models embed text into a latent space. Vision models embed images into a different latent space.

These two spaces are incompatible — a word vector and an image vector live in completely different coordinate systems.
The Key Question
Can we learn a shared embedding space where a photo of a cat and the text "a cat" land at the same location?
If yes — what becomes possible?
✦ Search images using natural language
✦ Zero-shot image classification
✦ Cross-modal retrieval
✦ Image captioning & visual question answering

CLIP — Contrastive Language-Image Pre-Training

📄 The Paper
Radford et al., OpenAI (2021)
"Learning Transferable Visual Models From Natural Language Supervision"
ICML 2021 · arxiv.org/abs/2103.00020
Core Idea
Train two encoders — one for images, one for text — to produce embeddings that are close for matching pairs and far apart for non-matching pairs.
Training Data
400 million image-text pairs collected from the internet. No manual labels — the captions are the supervision signal (natural language supervision).
Architecture
Image encoder: ViT (Vision Transformer) or ResNet
Text encoder: Transformer (GPT-2 style)
Both produce 512-dim L2-normalized embeddings

CLIP: Contrastive Loss & N×N Matrix

How the Loss Works
Given a batch of N image-text pairs, CLIP builds an N×N cosine similarity matrix. The loss pushes the diagonal (matched pairs) toward 1 and off-diagonal toward 0.
Why this works
1
Symmetric matching — loss pulls matched image→text AND text→image pairs together simultaneously
2
Many hard negatives — large batches (N=32,768) expose the model to thousands of wrong pairings at once
3
Scales with data — more training pairs → sharper separation between matched and unmatched embeddings
Zero-shot capability
After training, CLIP classifies images into any text-described category — no fine-tuning needed.
N×N Similarity Matrix (N=4 example)
Green diagonal = matched pairs · Loss maximizes these, minimizes all others

CLIP Embedding Power — Examples

Zero-Shot Image Classification
No fine-tuning on target classes needed. For any image, compute similarity against all candidate text prompts and pick the best match.
How it works
1
Build text prompts: "a photo of a {class}" for each candidate class
2
Encode image and all prompts with CLIP encoders
3
Compute cosine similarity → argmax = predicted class
ImageNet benchmark
CLIP achieves 76.2% top-1 accuracy on ImageNet zero-shot — matching supervised ResNet-50 with no training on ImageNet labels.

CLIP for Remote Sensing & GeoAI

🏔️ Image Retrieval with Free Text
CLIP allows querying a large database of satellite or aerial images using free-text descriptions — no manual labeling or category training required.
Example queries
“Find all images with flooded urban areas”
“Show images with dense informal settlements”
“Retrieve satellite images of deforestation”
“Find coastal erosion near river mouths”
Specialized Models
RemoteCLIP — fine-tuned CLIP on remote sensing image-caption pairs
GeoRSCLIP — geo-specific contrastive learning for RS imagery
SkyScript — 5.2M RS image-text pairs for training
GeoAI Applications
🏴 Image Captioning
Automatically generate text descriptions for satellite images — enables searchable geographic archives.
📍 Geo-Grounding
Align text mentions of locations with visual patches in remote sensing images — combine NER + CLIP.
📷 RS Image Retrieval
Search large RS image archives using free-text queries — find the right satellite scene without metadata labels.
🚀 Change Detection
Query before/after image pairs: "area affected by urban expansion" → detect land-use change automatically.

The Multi-Modal Horizon

CLIP showed vision + language can align. Modern foundation models go further — combining all modalities in a single unified representation space.
Unified Multi-Modal Models
1
Gemini 1.5 Pro (Google) — natively processes text, images, audio, video and code in one model
2
GPT-4o (OpenAI) — omni model with real-time understanding of text, vision and audio
3
Meta Chameleon — any-to-any generation across text, image, video and audio modalities
